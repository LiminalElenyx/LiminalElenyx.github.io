The Watchdog

The Watchdog is a locally inspired investigative blog site built with HTML, CSS, and foundational JavaScript. The project demonstrates responsive design principles, clean code structure, and a cohesive visual theme modeled after small-town journalism. It also incorporates basic JavaScript functions to enhance interactivity and user experience, serving as an early example of dynamic front-end development.

Goblet of Fire Emulator

A JavaScript project inspired by the Goblet of Fire, created to explore functions, conditional logic, and array methods by translating a fictional selection process into working code.
